# Dear Vincent artwork sources

The included wallpaper files are resized copies of public-domain works by
Vincent van Gogh. The paintings themselves are in the public domain because
the artist died in 1890. Source pages and attribution are retained here for
redistribution context.

The files in this repository are resized and cropped for 16:9 desktop use.
The source pages should be checked for any museum-specific reproduction notes
when redistributing outside jurisdictions that recognize public-domain status.
