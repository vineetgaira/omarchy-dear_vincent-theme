# Dear Vincent

An Omarchy theme inspired by Vincent van Gogh's night blues and ochre light.

The design is intentionally dark, quiet, and development-first: readable terminal
surfaces, restrained gold focus states, subtle motion, and artwork kept in the
background rather than placed over application content. It contains no quotes.

Included: Omarchy semantic palette, shell/bar surfaces, Hyprland borders and
performance-conscious animations, lock screen palette, GTK/Adwaita palette,
launcher styling, terminal-compatible colors, and a public-domain Van Gogh
wallpaper collection.

This theme is saved under the user theme directory and is not applied by this
package operation. Select **Dear Vincent** from the Omarchy theme switcher when
you are ready.

## Install

Copy the `dear-vincent` directory into `~/.config/omarchy/themes/`, or install
the repository with Omarchy:

```bash
omarchy theme install https://github.com/YOUR-ACCOUNT/omarchy-dear-vincent
```

After installation it appears in the theme switcher. Applying it is a separate
step:

```bash
omarchy theme set dear-vincent
```

The theme does not change keybindings, monitors, idle timers, or application
preferences. Wallpaper rotation is provided by Omarchy's normal background
switcher:

```bash
omarchy theme bg next
```

## What is included

- `colors.toml`: Omarchy's semantic palette for supported generated surfaces.
- `shell.toml`: bar, menu, launcher, notification, popup, lock, and control styling.
- `hyprland.lua`: borders, mild dimming, shadows, and restrained animations.
- `hyprlock.conf`, `gtk.css`, and `walker.css`: supported desktop surface styling.
- `backgrounds/`: four 2560×1440 public-domain Van Gogh artwork backgrounds.

Terminal colors are generated by Omarchy from `colors.toml`; Alacritty, Kitty,
Foot, and Ghostty therefore follow the same palette when the theme is applied.
Other editors and applications remain app-specific unless they support Omarchy's
theme integration or are manually configured.
